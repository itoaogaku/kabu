# かぶトラッカー

自分が買った・売った株を記録し、その株が今いくらになっているかを一目で確認できるダッシュボードです。
証券会社の取引メモのような、日付・銘柄・区分(購入/売却)・株数・単価・メモのフラットな取引履歴を記録すると、
銘柄ごとの保有株数・取得単価(加重平均)・評価損益・実現損益を自動で集計します。

**下落アラート**: 保有中の銘柄は平均取得単価から、売却済みの銘柄は前回の売却価格から、現在値が-15%以上
下がると「🔻買い時?」のバッジが表示されます。「前に買って(売って)いた株がグッと下がったら、また買いたい」
というときに使う機能です。

## 構成

- **[GAS版(`gas/`)](./gas/README.md)** — バックエンド。Google Apps Script + Google スプレッドシートで
  動く。データはスプレッドシートに保存され、株価は Yahoo Finance から取得する。単体でもウェブアプリとして
  使える。
- **[Vercel版(`web/`)](./web/README.md)** — フロントエンドのみ。見た目の良い URL で使いたい場合に、
  画面だけを Vercel でホストする。データの保存・株価取得は GAS版が担当するので、**先に GAS版のセットアップ
  が必要**。

どちらも同じ見た目・機能で、実体は同じ GAS の取引履歴データを見ている(Vercel版はただの窓口)。

## できること

- 取引の記録(証券コード or ティッカー、銘柄名、区分(購入/売却)、株数、単価、日付、メモ)
- 銘柄一覧で、保有中・売却済みを問わず一度でも取引した銘柄の現在値を自動取得
- 保有株数・取得単価(加重平均)・評価額・評価損益・実現損益を自動集計
- **下落アラート**(平均取得単価 or 前回売却価格から-15%以上下落で🔻バッジ、下落率順に自動ソート)
- 取引履歴の一覧・追加・編集・削除
- 銘柄ごとの株価推移チャート
- 「最新の株価に更新」ボタン、および5分ごとの自動更新
- iPhoneの「ホーム画面に追加」に対応(アプリのような見た目で起動)

株価は Yahoo Finance の公開チャートAPIから取得します(APIキー不要)。日本株は証券コード(例: `7203`)を
入力すると自動で `.T` を付与します。米国株などはティッカー(例: `AAPL`)をそのまま入力してください。

## 表示上の注意

騰落の色は日本の証券会社の慣習(上昇/プラス=赤、下落/マイナス=緑)に合わせています。

## セットアップ

1. [`gas/README.md`](./gas/README.md) の手順で GAS版をデプロイする(スプレッドシートの準備、
   Apps Script のコードの貼り付け、Web アプリとしてデプロイ)
2. 見た目の良い URL で使いたい場合は、続けて [`web/README.md`](./web/README.md) の手順で Vercel に
   フロントエンドをデプロイする(GAS版のURLとトークンを環境変数に設定するだけ)

## データ移行について

以前のバージョン(1購入=1行のロット管理方式)を使っていた場合、GAS の `Code.gs` に用意している
`migrateFromLegacyStocks()` を Apps Script エディタから1回実行すると、既存の `Stocks` シートの
データを新しい取引履歴形式(`Transactions` シート)に自動変換できます。詳しくは
[`gas/README.md`](./gas/README.md) を参照してください。
