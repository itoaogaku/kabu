# かぶトラッカー

自分が買ったことのある株の株価推移を自動で確認できるダッシュボードです。
購入価格・購入日・売却価格・売却日・メモを記録し、現在の株価と購入時(および売却時)からの騰落を一目で確認できます。

このリポジトリには2つの実装があります。

- **ローカル版(このディレクトリ直下)**: Flask + SQLite + yfinance。自分のPC/サーバーで動かす。
- **[GAS版(`gas/`)](./gas/README.md)**: Google Apps Script + Google スプレッドシート。デプロイすれば
  Google のサーバー上でホストされ、URL があればどこからでもアクセスできる。データはスプレッドシートに
  保存される。**ウェブアプリとして公開したい場合はこちらを使ってください。**

## できること

- 銘柄の追加(証券コード or ティッカー、株数、購入価格・日、メモ)
- 保有中の銘柄の現在値と購入時からの騰落率を自動取得(色分け表示)
- 売却記録(売却価格・日)の登録
- **売却済みの銘柄でも現在値を取り続け、「売却後に上がったか下がったか」を表示**(見送り確認)
- 銘柄ごとの株価推移チャート(購入日〜現在、または売却日まで)
- メモの追加・編集
- 「最新の株価に更新」ボタン、および5分ごとの自動更新

株価データは [yfinance](https://github.com/ranaroussi/yfinance) 経由で Yahoo Finance から取得します。
日本株は証券コード(例: `7203`)を入力すると自動で `.T` を付与して東証銘柄として取得します。米国株などは
ティッカー(例: `AAPL`)をそのまま入力してください。

## 表示上の注意

騰落の色は日本の相場慣習(上昇=赤、下落=青)に合わせています。

## セットアップ(ローカル版)

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python app.py
```

起動後、ブラウザで http://127.0.0.1:5000 を開いてください。

データは `data/kabu.db`(SQLite)に保存されます。

ウェブアプリとして公開し、データをスプレッドシートに保存したい場合は
[`gas/README.md`](./gas/README.md) の GAS版を参照してください。

## 構成(ローカル版)

- `app.py` — Flask アプリ本体・ルーティング
- `db.py` — SQLite へのデータアクセス層
- `stock_data.py` — yfinance を使った現在値・履歴取得(キャッシュ付き)
- `templates/index.html` — ダッシュボード画面
- `static/` — CSS・JS・Chart.js(ローカル同梱、CDN不要)
