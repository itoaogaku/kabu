# かぶトラッカー(GAS版)

Google Apps Script (GAS) で動くウェブアプリ版です。データは Google スプレッドシートに保存され、
株価は Yahoo Finance の公開チャートAPIを `UrlFetchApp` で直接呼び出して取得します
(APIキー不要)。デプロイすると Google のサーバー上でホストされる URL からどこでも
アクセスできます。

もともとはスプレッドシート組み込みの `GOOGLEFINANCE` 関数を使っていましたが、東証銘柄で
`#N/A` になったり、取引所プレフィックス無しの裸のティッカーだと**無関係な別の銘柄の値を
返す**ことを実際に確認したため、Yahoo Finance を直接叩く方式に変更しました。

機能は Flask版(リポジトリ直下)と同じです。

- 銘柄の追加(証券コード / ティッカー、株数、購入価格・日、メモ)
- 保有中銘柄の現在値と購入時からの騰落率(色分け表示)
- 売却記録(売却価格・日)
- 売却済み銘柄でも現在値を追跡し、「売却後に上がったか下がったか」を表示
- 銘柄ごとの株価推移チャート
- 5分ごとの自動更新 / 手動更新ボタン

## デプロイ手順(手動・推奨)

Google アカウントでの操作が必要なため、これはユーザー自身で行ってください。

1. 新しい Google スプレッドシートを作成する。
2. メニューの「拡張機能」→「Apps Script」を開く。
3. エディタに最初から入っている `Code.gs` の中身を全て削除し、このフォルダの
   [`Code.gs`](./Code.gs) の内容を貼り付ける。
4. 左側の「ファイル」の「+」→「HTML」で以下の4ファイルを作成し(拡張子 `.html` は自動で付く)、
   それぞれ同名ファイルの内容を貼り付ける。
   - `Index`
   - `Stylesheet`
   - `JavaScript`
   - `ChartJs`
5. 左側の歯車アイコン(プロジェクトの設定)で「"appsscript.json" マニフェスト ファイルを
   エディタで表示する」を ON にする。エディタに現れた `appsscript.json` の中身を
   [`appsscript.json`](./appsscript.json) の内容に置き換える。
6. エディタ上部の関数選択ドロップダウンで `setup` を選び、実行ボタン(▶)を押す。
   初回は権限の承認画面が出るので許可する。実行すると `Stocks` シートが自動作成される。
7. 右上の「デプロイ」→「新しいデプロイ」をクリック。
   - 種類の選択で「ウェブアプリ」を選ぶ。
   - 次のユーザーとして実行: 自分
   - アクセスできるユーザー: 自分のみ(個人の資産情報が入るため推奨。他の人にも
     見せたい場合のみ変更する)
   - 「デプロイ」をクリックし、発行された URL にアクセスすればダッシュボードが開く。

コードを更新した場合は、エディタ側のファイルを書き換えた後に
「デプロイ」→「デプロイを管理」→ 該当デプロイの編集(鉛筆アイコン)→
「新しいバージョン」を選んで再デプロイすると、同じ URL のまま更新が反映される。

## 外部フロントエンド(Vercelなど)から呼び出す場合の JSON API

[`../web/`](../web/) の Vercel 版フロントエンドのように、このスプレッドシート付属の
画面を使わず外部の静的サイトから操作したい場合、`Code.gs` は `?action=...` 付きの
GET リクエストで JSON API としても動作する。

```
GET {デプロイURL}?action=list&token=...
GET {デプロイURL}?action=add&token=...&ticker=7203&buy_price=3000&buy_date=2026-07-01&quantity=100&name=...&memo=...
GET {デプロイURL}?action=sell&token=...&id=...&sell_price=3200&sell_date=2026-08-01
GET {デプロイURL}?action=unsell&token=...&id=...
GET {デプロイURL}?action=memo&token=...&id=...&memo=...
GET {デプロイURL}?action=delete&token=...&id=...
GET {デプロイURL}?action=history&token=...&id=...
GET {デプロイURL}?action=refresh&token=...
```

レスポンスは `{"ok": true, "data": ...}` または `{"ok": false, "error": "..."}` の JSON。

この API を外部サイトから呼ぶには、以下の追加設定が必要になる。

1. **トークンを設定する**(必須。個人の保有株情報を守るため)
   プロジェクトの設定(⚙️)→「スクリプト プロパティ」→「スクリプト プロパティを追加」
   → プロパティ名 `API_TOKEN`、値に自分で決めたランダムな文字列(例: パスワード生成ツールで
   作った32文字程度の文字列)を入力して保存する。この値を後で Vercel 側の環境変数
   `GAS_API_TOKEN` に設定する。
2. **デプロイのアクセス権を「全員」に変更する**
   「デプロイ」→「デプロイを管理」→ 編集(鉛筆アイコン)→「アクセスできるユーザー」を
   「全員」に変更して再デプロイ(新しいバージョンとして)する。
   「自分のみ」のままだと、外部サイトからのアクセスは Google のログイン画面にリダイレクト
   されてしまい JSON が返らない。
   トークンチェックがあるので、URLとトークンを知らない第三者はデータを読み書きできない。
3. **Web アプリ URL(`/exec` で終わるもの)を控えておく**
   「デプロイを管理」の画面に表示される URL。テスト用の `/dev` URL ではなく、正式デプロイの
   `/exec` URL を使うこと。ブラウザで
   `{URL}?action=list&token={設定したトークン}` を直接開いて JSON が返れば設定完了。

## デプロイ手順(clasp を使う場合・任意)

コマンドラインでコードを push したい場合は [clasp](https://github.com/google/clasp) が使える。

```bash
npm install -g @google/clasp
clasp login
cd gas
clasp create --type webapp --title "かぶトラッカー"
clasp push
clasp deploy
```

`clasp create` で生成される `.clasp.json` にはスクリプトID(個人の Google アカウントに
紐づく)が含まれるため、リポジトリにはコミットしない([`.gitignore`](../.gitignore) 参照)。

## ティッカーの指定方法

入力値は大文字化した上で、Yahoo Finance の形式に正規化してから使う。

- 数字3〜4桁(+英数字1桁まで)の東証コード(例: `7203`、`166A`)→ 自動で `.T` を付与
  (`7203.T`、`166A.T`)
- 既に `.` や `:` を含む場合(例: `7203.T`、`NASDAQ:AAPL`)→ そのまま使用
- それ以外(例: `AAPL`)→ 大文字化してそのまま使用

見つからない・値がおかしい場合は、Yahoo Finance のサイト(finance.yahoo.com)で銘柄を
検索し、そこに表示されているティッカー表記(例: `7203.T`)をそのまま入力してみること。

過去に `GOOGLEFINANCE` 版で登録した行は `gf_ticker` 列が `TYO:7203` や `7203`(プレフィックス
無し)のままになっており、現在値が更新されない。Apps Script エディタの関数選択で
`resyncTickers` を選んで実行すると、`ticker` 列(元の入力値)から `gf_ticker` 列を
最新のロジックで再計算できる。実行後、ダッシュボードの「最新の株価に更新」ボタンを押すか
`refreshPrices` を実行すると現在値が入る。

## 制限事項

- Yahoo Finance のこのエンドポイントは非公式(ドキュメント化されていない)ため、
  Yahoo 側の仕様変更で将来使えなくなる可能性がある。
- 裸のティッカー(取引所指定なし)が稀に無関係な別の銘柄に解決されることがある
  (`GOOGLEFINANCE` で実際に発生した問題)。`.T` 付きなど、できるだけ明確な形式で
  入力すること。追加・インポート直後は、表示された現在値が実際の株価とだいたい
  合っているか目視確認することを推奨する。
- 現在値は取得後 `CacheService` で5分程度キャッシュされる(同じ銘柄への連続アクセスで
  Yahoo に負荷をかけすぎないため)。「最新の株価に更新」ボタンはこのキャッシュを無視して
  強制的に再取得する。
- 複数人が同時に大量の操作をすると `UrlFetchApp` の1日あたりの呼び出し上限
  (個人アカウントで概ね20,000回/日)に近づく可能性があるが、個人〜少人数利用の範囲では
  通常問題にならない。

## ファイル構成

- `Code.gs` — サーバーサイドロジック(スプレッドシートCRUD・Yahoo Finance連携)
- `Index.html` — ページ本体
- `Stylesheet.html` — CSS
- `JavaScript.html` — クライアント側ロジック(`google.script.run` でサーバー関数を呼ぶ)
- `ChartJs.html` — Chart.js をローカル同梱(CDN不要)
- `appsscript.json` — プロジェクトマニフェスト
